# MEMORY.md — Memória de Longo Prazo do Agente (OptMem Pattern)

Este arquivo armazena a persistência de contexto, decisões estruturais e fatos permanentes do ambiente.
Atualizado de forma contínua pelo agente autônomo ao concluir tarefas ou introduzir novas convenções.

---

## Estado Atual do Repositório
- **Versão**: 1.0.0 (Base Starter Kit / Agentic Knowledge OS)
- **Modo**: Scaffold Inicial Pronto para Uso
- **Stack**: Python 3.11+, Playwright Chromium, Node.js 20+, React/MDX, Mermaid.js
- **Motor de PDF**: Playwright Headless com layout corporativo A4 anti-órfão (`scripts/gerar_pdf.py`)
